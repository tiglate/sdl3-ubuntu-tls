# Development packages the builds detect optional backends from. Nothing here
# is strictly required -- a missing package just disables the backend it feeds --
# but installing the lot is what produces fully featured packages.
#
# Install them with:
#   sudo apt install $(grep -vE '^\s*(#|$)' build-deps.txt)
#
# This file is the single source of truth: the CI workflows install exactly
# this list. Run ./make.sh features after a build to see what was enabled.
#
# It is derived from the upstream projects' own documented and CI dependency
# lists, not from whatever happens to be on one developer's machine -- a package
# missing here builds fine locally if it is already installed, and only fails on
# a clean runner. Deliberately excluded: the ffmpeg libraries and libunwind,
# which upstream installs only to build its test programs (we configure with
# tests off), and libaudio-dev, whose NAS driver SDL3 no longer has.

# --- toolchain ---
build-essential
cmake
ninja-build
git
pkg-config
dpkg-dev

# --- audio ---
libasound2-dev
libpulse-dev
libpipewire-0.3-dev
libjack-jackd2-dev
libsndio-dev

# --- video: X11 ---
libx11-dev
libxext-dev
libxrandr-dev
libxcursor-dev
libxfixes-dev
libxi-dev
libxss-dev
libxkbcommon-dev
# XTEST is enabled by default and SDL treats a missing dependency for an
# enabled X11 option as a hard configure error, not a silent downgrade.
libxtst-dev
# Neither of these is pulled in transitively by the packages above, and both
# are probed directly: Xrender.h and Xproto.h.
libxrender-dev
x11proto-dev

# --- video: Wayland and KMS/DRM ---
